Research these four AI coding tools and produce a structured comparison in markdown.

1. **Caveman** — https://github.com/JuliusBrussee/caveman

3. **Ponytail** — https://github.com/DietrichGebert/ponytail

## For Each Tool, Find

- Core purpose and what problem it solves
- How it works (architecture/mode of operation)
- Key differentiating features
- Any stated philosophy or principles

## Research Methods

1. Use firecrawl or pi-web-access to scrape each GitHub repo README and docs
2. Search the web for articles, videos, or discussions comparing these tools
3. Look for how they might work together or complement each other
